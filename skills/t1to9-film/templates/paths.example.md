# paths.local.md: đường dẫn trên máy này

Chép file này thành `paths.local.md` cạnh `SKILL.md`, rồi điền giá trị của máy mình. `paths.local.md` không được commit.

| Khoá | Là gì | Giá trị trên máy này |
|---|---|---|
| `<T1_KNOWLEDGE>` | Clone của `tue0111/t1-visual-knowledge` (có `tools/t1lint.py`) | |
| `<T1_PROMPT_OS_LEGACY>` | Bản OS prompt cũ (`MASTER_INDEX.md`), chỉ để tra sâu | |
| `<FILM_LIBRARY_MCP>` | Thư mục server MCP `film-library` | |
| `<PREV_FILM>` | Thư mục phim trước (*mùa hè cuối cấp*), có `tools/` dùng lại | |
| `<JEV_SERVER>` | Thư mục server Jev (`index.js`) | |
| `<STUDIO>` | Thư mục studio có `docs/script-critique.md` | |
| `<GUYI_NOTES>` | Ghi chép phân tích lối cắt của 古一 | |
| `<PY312>` | Python có cv2, numpy, librosa | |
| `<FFMPEG_DIR>` | Thư mục chứa ffmpeg/ffprobe (đặt thêm biến môi trường `FFMPEG_DIR`) | |

Khoá nào để trống thì phần việc dùng khoá đó coi như không có nguồn: báo người làm phim, không đoán đường dẫn.
